# 🌍 AgriShift - NASA Space Apps Challenge 2026
**Challenge:** Field Shift: Adapting Farms with NASA Data

## About the Project
AgriShift is an AI-powered Decision Support System for farmers. By combining **NASA's GPM** (Precipitation) and **ECOSTRESS** (Land Surface Temperature) data with a Random Forest Machine Learning model, it predicts and recommends optimal crop rotation strategies to combat climate change.

## How to Run Locally
1. Clone the repository
2. Install requirements: `pip install -r requirements.txt`
3. Run the web app: `streamlit run app.py`

## Technologies Used
- **Frontend:** Streamlit
- **AI/ML:** Scikit-learn (Random Forest Classifier)
- **Data Sources:** NASA Earthdata (GPM, ECOSTRESS)
